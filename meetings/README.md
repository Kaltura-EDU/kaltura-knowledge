# Meeting summaries

AI-generated summaries of Kaltura-EDU community meetings, named by date (`YYYY-MM-DD.md`).

**These are discussion records, not verified guidance.** They include questions, guesses, and things individual participants have observed in their own environments. Treat everything here as `Unverified`.

If a summary contains a lesson worth keeping, write it up as a note in [`notes/`](../notes) and cite the meeting date in `source`.

Before submitting a summary, remove personal names and institution-specific details unless the person agreed to be included.
