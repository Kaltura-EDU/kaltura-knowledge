# Notes

Curated knowledge notes, grouped by topic. Each note uses the [template](../templates/knowledge-note.md) and carries a `status` showing how well established it is.

| Folder | Topics |
|---|---|
| [`api/`](api) | API behavior, quirks, error codes, filters, pagination, session handling |
| [`players/`](players) | Players, embedding, playback, and UI configuration |
| [`captions/`](captions) | Captions, REACH, transcripts, and accessibility workflows |
| [`permissions/`](permissions) | Roles, categories, channels, sharing, and access control |
| [`troubleshooting/`](troubleshooting) | Symptom-first fixes and workarounds that cross topics |

Need a new folder? Propose it in your pull request.
